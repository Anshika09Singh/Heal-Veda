# 🌿 Heal Veda – AI-Powered Wellness Assistant

Heal Veda is a web-based AI wellness application designed to help common users
understand prescriptions, check medicine safety, and receive personalized
herbal wellness guidance in **simple, human-friendly language**.

The platform combines **OCR, rule-based logic, and Generative AI** to bridge the
gap between complex medical information and everyday understanding.

---

## 🚀 Key Features

- 📸 **Prescription Scanner**
  - Upload prescription images
  - Extract medicine names using OCR
  - Explain medicines in simple language
  - Provides timing guidance and safety alerts
  - Voice-based explanation support (Text-to-Speech)

- ⚠️ **Medicine Safety Check**
  - Checks interactions between allopathic medicines and Ayurvedic herbs
  - Considers body type (Prakriti) and symptoms
  - Gives clear risk level and actionable advice

- 🌱 **Personalized Herbal Plan**
  - Generates herbal wellness plans based on:
    - Body type (Vata / Pitta / Kapha)
    - Wellness goal
    - Lifestyle
    - Current medicines
  - Simple explanations with safety notes

- 🔊 **Voice Assistance**
  - Reads AI-generated explanations aloud
  - Improves accessibility for elderly and non-technical users

## 🛠️ Tech Stack

### Frontend
- HTML5 – Page structure
- Tailwind CSS – Responsive and clean UI
- JavaScript – API calls, UI updates, logic
- Web Speech API – Text-to-speech (speaker feature)

### Backend
- Python – Core backend language
- Flask – REST API and routing
- Flask-CORS – Frontend-backend communication
- dotenv – Secure environment variable management

### AI & Machine Learning
- EasyOCR – Extracts text from prescription images
- Google Gemini API – Generates simplified AI explanations
- Prompt Engineering – Ensures safe, non-diagnostic outputs

### Logic & Intelligence
- Rule-based system – Medicine timing & safety rules
- Hybrid AI approach – Rule-based logic + Generative AI
- Risk scoring – Low / Moderate / High risk assessment
